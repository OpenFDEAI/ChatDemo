# 宏达机械 Demo Spec（2026-07-25）

## 目标场景
给售后总监演示「报修派工中心」：把 Excel + 微信群的人肉派工，换成超时可见、
派工有据的一屏。<!-- R0 09:59 会前假设，待现场校准 -->

## 底座与复用
templates/base（自研模板，MIT）。画廊 refine 未验证不进现场（铁律）。
品牌化：theme.json 一处修改——主色 #1e7d46 取自旧系统截图顶栏，术语取自
截图表头（报修单/派工/承诺时限/责任工程师）。

## 角色与用户
- 售后总监刘建国：看全局、看超时、看考核（月度超时率红线 10%）
- 内勤/值班长：每日 17:00 前人工派工登记（旧流程痛点）
- 维修工程师（周德旺、吴小军…）：接单执行
