# 宏达机械 Demo 演示台词稿（约 5 分钟）

演示地址：http://localhost:3000（投屏窗口只留浏览器）

1. **开场（列表页，默认管理员视角）**
   「这就是贵方的报修单——BX 单号、机型、故障码、责任工程师，字段结构
   就是你们 API 文档 v1.1 的，不是我们编的。」

2. **打动点 1：超时置顶**（停留 10 秒，让客户自己看）
   「您说紧急单压在群里没人看——现在超时的单红色顶在最上面，这单压了
   11 天，一进系统就躲不掉。」

3. **打动点 2：建议派工**（点开一张「待派工」的单，或直接开 `?open=BX-10248`）
   「待派工的单，打开就有人选。排序就是您的口诀——先看远近、再看忙闲，
   每个人选都写了为什么：擅长这个故障码、哪个区常驻、手头几张单。」

4. **老板视角：区域考核看板**（回列表页顶部）
   「您老板每周一要的那页：每个区一个大数字，超线红灯、达标绿灯——
   华东 15.6、华北 19.5，超了 10% 红线，一眼点名。这是按 6 月报表做的，
   接上系统后每周自动出。」

5. **一线视角**（顶栏切到「维修工程师」，或 `?role=agent`）
   「切到维修工程师登录——只看自己名下的单，考核看板不给一线看。」

6. **收口（打开 DEMO_SPEC.md 投屏）**
   「今天确认的都在这页纸上：三个做了的、一个您否掉的（横条图）、四个
   暂缓的——暂缓项里哪些是演示假数据我都标了。下一步建议两周 POC：
   接真实 API、派工写库、考核周报自动化。下周约个时间带凭证联调？」

—— 备注：全程不展示终端/代码；客户提问超出已做范围时，答「记进暂缓项，
会后给方案」，不现场即兴开发。
