# Demo 画廊：预验证开源项目池

按领域 curated 的「现场可直接用」的开源项目池。**只有画廊里的项目允许在
客户现场使用**——陌生项目 build 翻车会烧掉整个回合预算（铁律见
`../references/oss-first.md`）。

## 条目格式（每项目一个 `<slug>.md`）

```markdown
# <项目名>
- repo: <owner/name>
- license: <SPDX>（AGPL/GPL 标 ⚠）
- 领域: <工单 / BI / 图片生成 / …>
- 验证状态: ✅ 已跑通（<日期>，node <版本>）/ 🕓 待验证
- 启动命令: <实测通过的完整命令序列>
- 品牌化适配点: <theme/logo/术语分别改哪个文件>
- 已适配场景: <客户场景一句话，可多条>
- 坑: <实测遇到的问题与绕法>
```

## 使用纪律

- **会前**验证：clone → 跑通 → 记录启动命令与坑 → 才能标 ✅；
- **收尾回填**：每次拜访用过/验证过的项目，当天回填或更新条目；
- 验证状态超过 90 天未复验的，用前重新跑一遍（依赖会烂）。
